Atur titik

Citra Google Satellite memerlukan Google Maps API key milik Anda. Buat di Google Cloud Console: aktifkan Maps JavaScript API, buat API key, lalu batasi key itu ke situs ncukahkudai.github.io. Key hanya tersimpan di HP ini.
