Kebijakan Privasi

Aplikasi Catatan Lapangan · berlaku sejak 19 Oktober 2026

Ringkasnya: semua foto, catatan, dan koordinat yang Anda buat hanya tersimpan di perangkat Anda sendiri. Aplikasi ini tidak mengirimkan data apa pun ke server kami atau pihak lain.

Data yang dipakai aplikasi

  • Lokasi (GPS) dipakai untuk mencatat koordinat titik foto. Lokasi hanya dibaca saat aplikasi terbuka dan hanya disimpan bersama foto di perangkat Anda.
  • Kamera dan foto dipakai saat Anda menekan "Ambil Foto" atau memilih foto dari galeri. Foto disimpan di penyimpanan aplikasi di perangkat Anda.
  • Judul dan catatan yang Anda ketik disimpan di perangkat Anda.

Data yang tidak kami kumpulkan

Aplikasi ini tidak memiliki akun pengguna, tidak memakai iklan, tidak memakai analitik atau pelacak, dan tidak mengirim foto, lokasi, maupun catatan ke server mana pun. Kami tidak bisa melihat data Anda.

Berbagi data

Data hanya keluar dari perangkat jika Anda sendiri yang melakukannya, misalnya dengan menekan "Ekspor ke Google Earth" lalu membuka atau mengirim file .kmz ke aplikasi lain, atau menekan "Buka di Google Earth" / "Google Maps" yang mengirim koordinat titik tersebut ke aplikasi Google. Setelah itu berlaku kebijakan privasi aplikasi tujuan.

Menghapus data

Anda bisa menghapus foto satu per satu lewat tombol "Hapus" di aplikasi. Menghapus aplikasi atau menghapus data situs ncukahkudai.github.io di pengaturan Chrome akan menghapus semua data aplikasi dari perangkat.

Anak-anak

Aplikasi ini ditujukan untuk pekerjaan survey lapangan dan tidak ditujukan untuk anak-anak.

Kontak

Pertanyaan tentang kebijakan ini dapat dikirim melalui halaman GitHub ncukahkudai.
